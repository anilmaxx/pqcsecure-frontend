# pqcsecure-frontend

React + Vite frontend for the PQCSecure demo application.

## Setup
```bash
cd pqcsecure-frontend
npm install
```

## Run locally
```bash
npm run dev
```

## Build
```bash
npm run build
```

## Environment
Create a `.env` file if needed and set:
```bash
VITE_API_URL=http://localhost:5001/api
```

The frontend uses this value as the backend API base URL.
